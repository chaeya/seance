# Séance Keyboard Shortcuts

This document lists the default shortcuts baked into Séance. Every binding can be changed in the Settings dialog, and disabled bindings can be set to `unset`.

## Help

- `F1`: Show the shortcuts overlay

## Workspaces

- `Ctrl+PageUp`: Previous workspace
- `Ctrl+PageDown`: Next workspace
- `Ctrl+Shift+Backspace`: Last workspace
- `Ctrl+Alt+Backspace`: Last pane
- `Alt+1` to `Alt+9`: Switch to workspace 1 through 9
- `Ctrl+Alt+N`: New workspace
- `Ctrl+Alt+W`: Close workspace
- `Ctrl+Shift+G`: Workspace switcher

## Tabs

- `Ctrl+Shift+T`: New tab
- `Ctrl+Shift+W`: Close tab
- `Ctrl+Tab`: Next tab
- `Ctrl+Shift+Tab`: Previous tab
- `Ctrl+1` to `Ctrl+9`: Switch to tab 1 through 9
- `Ctrl+Alt+T`: Close other tabs
- `Ctrl+Alt+R`: Rename tab

## Panes

- `Ctrl+Shift+Enter`: New column
- `Ctrl+Shift+X`: Close pane
- `Ctrl+Shift+Left`: Focus left
- `Ctrl+Shift+Right`: Focus right
- `Ctrl+Shift+Up`: Focus up
- `Ctrl+Shift+Down`: Focus down

## Terminal

- `Ctrl+Shift+C`: Copy
- `Ctrl+Shift+V`: Paste
- `Ctrl+Shift+K`: Clear scrollback
- `Ctrl+Shift+F`: Find
- `Ctrl+Shift+E`: Use selection for find
- `F3`: Find next
- `Shift+F3`: Find previous

## Font

- `Ctrl+=`: Zoom in
- `Ctrl+-`: Zoom out
- `Ctrl+0`: Reset zoom

## UI

- `Ctrl+Shift+B`: Toggle sidebar
- `Ctrl+Shift+I`: Toggle notifications
- `Ctrl+Shift+U`: Jump to unread
- `Ctrl+Shift+H`: Flash focused pane
- `Ctrl+Shift+R`: Rename workspace
- `Ctrl+Shift+J`: Toggle pin

## Window

- `Ctrl+Shift+N`: New window
- `Ctrl+Shift+Q`: Quit application

## General

- `Ctrl+Shift+P`: Open command palette
- `Ctrl+Shift+O`: Open folder
- `Ctrl+,`: Open settings
- `Ctrl+Shift+,`: Reload config

## Layout and Resize

- `Ctrl+Shift+L`: Toggle layout mode
- `Ctrl+Shift+A`: Move column left
- `Ctrl+Shift+D`: Move column right
- `Ctrl+Alt+Left`: Expel left
- `Ctrl+Alt+Right`: Expel right
- `Ctrl+Shift+=`: Resize column wider
- `Ctrl+Shift+-`: Resize column narrower
- `Ctrl+Shift+M`: Maximize column
- `Ctrl+Shift+S`: Cycle preset column width
- `Ctrl+Alt+=`: Resize row taller
- `Ctrl+Alt+-`: Resize row shorter

## Notes

- Keyboard shortcuts are handled by the main window controller, so they apply to the focused window.
- When the command palette is open, only the palette toggle and workspace switcher shortcuts remain active.
- Most shortcuts can also be viewed inside the app via the shortcuts overlay.
